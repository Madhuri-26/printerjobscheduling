LINKED LIST QUEUE VISUALIZER

How to run:
1. Extract linked_list_queue_website.zip.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. No installation or internet connection is required.

Features:
- Enqueue print jobs at the rear
- Dequeue/print the oldest job from the front
- Visual linked nodes and next pointers
- FRONT and REAR indicators
- Waiting job/page counters and activity log
- Example jobs and clear queue
- Responsive layout for desktop and mobile

Implementation:
- HTML + CSS + vanilla JavaScript
- Queue represented by a JavaScript array for the demo's state, with each item rendered as a linked-list node and explicit next links in the visualizer.
- Enqueue and dequeue are demonstrated as O(1) linked-list operations conceptually.
