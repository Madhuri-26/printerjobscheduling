01 · Enqueue O(1)

Create a node and attach it after REAR. Then move REAR to the new node. If the queue was empty, FRONT and REAR both point to it.

02 · Dequeue O(1)

Remove the node at FRONT and move FRONT to its next node. If the queue becomes empty, set REAR to NULL too.

03 · FIFO order

First In, First Out: the oldest submitted print job is always the next one printed. The linked list grows as jobs are added.
